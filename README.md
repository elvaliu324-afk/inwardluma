# Inward Luma｜留白

中文、手机优先的单文件静态网站。index.html 包含全部 HTML、CSS 与 JavaScript，双击即可离线打开。

## Netlify 自动部署

- GitHub 仓库：elvaliu324-afk/inwardluma。
- 生产分支：main。
- 发布目录：仓库根目录（.）。
- 无构建命令，无依赖安装，无环境变量。
- netlify.toml 保存发布设置；连接 GitHub 后，main 的新提交会自动更新网站。
- HTTPS 平台网址验证成功后，再添加自定义域名；DNS 记录以平台实际返回内容为准。
